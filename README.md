# ひとやすみマップ

赤ちゃんや小さな子とのおでかけ中に、近くの **授乳室・おむつ替えスペース・遊び場・児童館・子連れで入りやすい飲食店** を地図で探せるサイトです。登録なし・無料・広告なし。

## データ

- 東京都福祉局「赤ちゃん・ふらっと一覧」（令和8年10月28日時点）を加工して作成（`data/akachan_flat.json`）。位置は国土地理院の住所検索で付けています
- © OpenStreetMap contributors（ODbL）。東京都内の分は `data/osm_tokyo.json` に同梱し、都外はその場で Overpass API から取得します

営業時間や設備は変わることがあります。行く前に施設の案内でたしかめてください。

## 位置情報

現在地は端末の中で使い、近くの施設の検索のために座標だけを Overpass API に送ります。このサイトは位置も検索内容も保存しません。アクセス解析も入れていません。

## 中身

```
index.html / style.css / app.js   サイト本体（ビルド不要の静的ファイル）
data/akachan_flat.json            東京都の授乳・おむつ替えスペース
data/osm_tokyo.json               東京都内の遊び場・児童館・お店など（OpenStreetMap から月1回ほど作り直す）
```
