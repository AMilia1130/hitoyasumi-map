# ひとやすみマップ

赤ちゃんや小さな子とのおでかけ中に、近くの **授乳室・おむつ替えスペース・遊び場・児童館・子連れで入りやすい飲食店** を地図で探せるサイトです。登録なし・無料・広告なし。

## データ（東京都の全域）

- 東京都福祉局「赤ちゃん・ふらっと一覧」「子育て応援とうきょうパスポート協賛店一覧」
- 都内の区市町村が公開している「公衆トイレ一覧」（乳幼児用設備のあるもの）「子育て施設一覧」「公園一覧」など
- © OpenStreetMap contributors（ODbL）

各データ（CC BY）を加工して `data/tokyo.json` にまとめています。出どころの一覧はサイトの「このサイトについて」に出ます。位置は国土地理院の住所検索で付けています。
営業時間や設備は変わることがあります。行く前に施設の案内でたしかめてください。

## 位置情報

現在地は端末の中で「近い順」に並べるためだけに使い、どこにも送りません。アクセス解析も広告も入れていません。

